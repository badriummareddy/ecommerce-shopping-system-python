# 🛒 E-Commerce Shopping System

## Description
A simple E-Commerce Shopping System built using Python and Object-Oriented Programming (OOP). Users can browse products, add them to a shopping cart, view their cart, and generate a final bill with GST.

## Features
- 🛍️ View Products
- ➕ Add Products to Cart
- 🛒 View Shopping Cart
- 💳 Checkout
- 🧾 Automatic Bill Calculation

## Technologies Used
- Python 3
- Object-Oriented Programming (OOP)

## Concepts Used
- Classes and Objects
- Dictionary
- Loops
- Conditional Statements
- Cart Management

## How to Run

```bash
python ecommerce_system.py
```
